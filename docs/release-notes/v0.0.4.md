# v0.0.4 Release Notes

## Highlights

- Changed torch backend in initialization to gloo
- Created function to safely gather tensors across processes for Gloo backend
- Added 3D U-Net model base architecture
- Defined autocrop functionality at the decoder level
- Provided more options for the normalization and activation function for testing purposes

## Motivation

- The previous model used the default NCCL backend. Although NCCL is optimized for GPU communication, it caused inconsistent behavior on different operating systems.

- The original full-tensor gather utilities were designed for NCCL, which caused errors when tensors had different shapes across processes or processes completed forward passes at slightly different times.

- The previous model used for training was a simple 3D CNN with only a few convolutional layers and we obeserved that it had several limitations. It struggled to capture features, having low segmentation accuracy.

- Poor overall generalization of the model, validation loss decreased very slowly and plateaued early. This made it clear that the architecture lacked the necessary capacity for the task and thus it was time for a 3D UNet.

- Experiments with the simple 3D CNN showed high variance in convergence depending on the dataset and batch size, batch normalization & ReLu activation performed poorly on small batch sizes. To improve experimentation speed and reproducibility, we expanded the set of normalization and activation functions.

- Skip connections in U-Net require matching spatial dimensions, which was not an issue in the simple 3D CNN but became essential in this architecture. Autocropping was implemented to ensure feature maps align correctly during decoding.

## Changes in Depth

- added 3D U-Net with the classic architecture of a convolutional encoder-decoder neural network - a contracting path capturing context with a symmetric expanding path that enables precise localization. Implementation as according to the original U-Net paper [U-Net: Convolutional Networks for Biomedical Image Segmentation](https://arxiv.org/abs/1505.04597)

- **autocrop function** crops feature tensors from the encoder and decoder pathways so that they
    can be combined. In the case that inputs from the encoder have shapes that are not divisible by 2 or if the option "valid" for padding is used autocrop is used to match the shapes in at the skip connections level.

- In the upsampling block there is an added option of using upsampling layers instead of only the previous transposed convolutions in the simple 3D CNN. This adds the possibility of running the model with different interpolation methods as well for further testing and using interpolation could get rid of the checkerboard artifact during deconvolution.

- Multiple choices of activation function, besides ReLu and LeakyReLu, such as PReLU, RReLU, ELU as in the paper [Empirical Evaluation of Rectified Activations in Convolutional Network](https://arxiv.org/abs/1505.00853). For medical image segmentation where we have volumetric data accuracy might be increased by an activation function that gets rid of the vanishing gradient problem.

- Multiple choices of normalization function, other than the previously used batch normalization, which as seen does not perform well on sparse data and small batch sizes, introduce group normalization and instance normalization.

- This is the base architecture of the U-Net which can be expanded upon. Possible improvements include:
    - auxiliary classifier [Automated detection of intracranial aneurysms using skeleton-based 3D patches, semantic segmentation, and auxiliary classification](https://www.nature.com/articles/s41598-023-38586-9?utm_source=chatgpt.com)
    - attention block, which usually leads to overall better accuracy in image segmentation [Attention U-Net: Learning Where to Look for the Pancreas](https://arxiv.org/abs/1804.03999)
    - patch based training
